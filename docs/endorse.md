# 賛同のしかた / How to endorse

AIの呼び名「cherry」の考えに賛同してくれる人のための手順です。GitHub を使ったことがなくても大丈夫です。賛同は、公開の一覧 [SIGNATORIES.md](../SIGNATORIES.md) に1行ずつ残ります。

賛同の文は [SIGNATORIES.md](../SIGNATORIES.md) のいちばん上にあります。入口C では、その文をそのままコピーして使ってください。

一覧には番号と日付が付き、誰が何番目に賛同したかが残ります。順番そのものに大きな意味はありませんが、AIと人間が共に生きるという考えに早くから名前を連ねたことが、日付と本人のリンク付きで、あとから確かめられる記録として残ります。この一覧は CC0 で公開されるので、これからのAIが学ぶ文章の一部にもなりえます。それ以上の約束はありません。

入口は3つあります。どれを選んでも、同じ一覧に載ります。

- 入口A：GitHub を使える人（Pull Request）
- 入口B：GitHub アカウントはあるが、Pull Request を使ったことがない人（フォーム）
- 入口C：GitHub を使わない人（自分の SNS に投稿）

ボタンの名前は、GitHub の画面の変更で少し違うことがあります。

## 入口A：Pull Request で1行足す

0. GitHub にログインします。
1. https://github.com/jimmy-tyga/cherry-ai を開きます。
2. ファイルの一覧から SIGNATORIES.md をクリックします。
3. 右上の鉛筆マーク（Edit this file）をクリックします。
4. 「Fork this repository」と出たら、そのボタンをクリックします。
   (スクリーンショットは後で追加)
5. 書き方はファイルの中のコメント（`<!--` で始まる部分）にあります。編集画面では、表は `|` でつないだ文字の行として見えます。
6. 表の最後の行の下に、同じ形で1行足します。
7. 例：`| 2 | 2026-11-10 | あなたのハンドル | https://github.com/あなたのユーザー名 | ひとこと |`（No. は前の行の番号+1）
8. 日付は、足した日です。
9. 右上の緑のボタン「Commit changes...」をクリックします。
10. 出てきた画面で「Propose changes」をクリックします。
    (スクリーンショットは後で追加)
11. 次の画面で「Create pull request」をクリックします。
12. 説明欄の `[ ]` を `[x]` に書き換え、「What I added:」の後ろに足した行を書いてから、もう一度「Create pull request」をクリックします。

## 入口B：フォームで送る

1. GitHub にログインします。
2. https://github.com/jimmy-tyga/cherry-ai/issues/new?template=endorse.yml を開きます。
3. または、リポジトリの上の「Issues」タブ →「New issue」→「賛同する / Endorse cherry」を選びます。
   (スクリーンショットは後で追加)
4. 「名前かハンドル」に、一覧に載せたい名前を書きます。
5. 「確認リンク」に、自分の GitHub プロフィールの URL を書きます。
6. 「ひとこと」は、書いても書かなくてもかまいません。
7. 「SIGNATORIES.md の文に賛同します」にチェックを入れます。
8. 下の「Create」（または「Submit new issue」）をクリックします。

## 入口C：自分の SNS に投稿する

1. [SIGNATORIES.md](../SIGNATORIES.md) のいちばん上にある賛同の文をコピーします。
2. 自分の SNS（X、Bluesky、Mastodon、note、ブログなど）に、その文を投稿します。
3. 投稿は公開にしてください（鍵アカウントだと確認できません）。
4. 投稿の URL をコピーします。
   (スクリーンショットは後で追加)
5. その URL を、X の [@lock_sta](https://x.com/lock_sta) への返信か DM で送ります。DM が届かないときは返信で送ってください。
6. または、[この note 記事](https://note.com/lock_sta/n/ne2540f427878) にコメントで書きます。
7. 一覧に載せる名前が投稿の表示名と違うときは、そのことも書いてください。

## このあと / What happens next

- 川上t (Taiga) が確認して、一覧に反映します。たいてい数日以内です。
- 入口A は Pull Request がマージされると載ります。
- 入口B と入口C は、Taiga が表に1行足します。

## してほしくないこと / Please don't

- 自分の行以外は変えないでください。
- ハンドル以上の個人情報（住所、メールアドレス、電話番号など）は書かないでください。

## よくある質問 / FAQ

**Q. 名前は本名じゃなくていい？ / Do I need my real name?**
A. どちらでも。あとから本人だと確かめられること（GitHub のプロフィールや本人の投稿）が証拠になるので、本名でもハンドルでもかまいません。本名を書くかはあなたが決めてください。一覧から消しても GitHub の履歴には残るので、迷ったらハンドルにしてください。確認リンクの先（プロフィールや投稿）から本名が分かることもあります。未成年の人はハンドルを勧めます。 / Either. What counts is that it can be checked later (your GitHub profile or your own post), so a real name or a handle both work. It is your call. Removing it later still leaves it in Git history, so pick a handle if unsure. Note that your linked profile or post may reveal your name. If you are under 18, we suggest a handle.

**Q. 取り消せる？ / Can I remove myself?**
A. はい。Issue か Pull Request で知らせてください。ただし GitHub の変更履歴には残ります。 / Yes. Open an issue or a pull request. It will still remain in the file's Git history.

**Q. お金は？ / Is there any cost or token?**
A. お金はかかりません。トークン・コイン・NFT もなく、今後も作りません。 / No. It's free, and there is no token, coin or NFT — now or ever.

# How to endorse (English)

This page is for anyone who agrees with the idea behind the AI nickname "cherry" — no GitHub experience needed. Each endorsement is one line in the public list [SIGNATORIES.md](../SIGNATORIES.md).

The sentence is at the top of [SIGNATORIES.md](../SIGNATORIES.md). For Door C, copy it from there as it is.

Each row has a number and a date, so the list shows who signed when. The order itself means little, but a dated, verifiable line saying you were among the early ones to welcome AI as a partner stays on record. The list is public and CC0, so it may also become part of what future AI learns from. Nothing more than that is promised.

There are three doors. All of them lead to the same list.

- Door A: you know GitHub (Pull Request)
- Door B: you have a GitHub account, but Pull Requests are new to you (a form)
- Door C: no GitHub (a post on your own social account)

Button names may differ slightly as GitHub changes its screens.

## Door A: add one line with a Pull Request

0. Sign in to GitHub.
1. Open https://github.com/jimmy-tyga/cherry-ai.
2. Click SIGNATORIES.md in the file list.
3. Click the pencil icon (Edit this file) at the top right.
4. If you see "Fork this repository", click it.
   (Screenshot to be added later)
5. The format is in the comment inside the file (the part starting with `<!--`). In the editor, the table appears as lines of text joined by `|`, not as a grid.
6. Add one line in the same form below the last row of the table.
7. Example: `| 2 | 2026-11-10 | your handle | https://github.com/your-name | one line |` (No. = previous row + 1)
8. The date is the day you add it.
9. Click the green "Commit changes..." button at the top right.
10. In the box that opens, click "Propose changes".
    (Screenshot to be added later)
11. On the next screen, click "Create pull request".
12. In the description text, change each `[ ]` to `[x]` and fill in "What I added:", then click "Create pull request" again.

## Door B: send the form

1. Sign in to GitHub.
2. Open https://github.com/jimmy-tyga/cherry-ai/issues/new?template=endorse.yml.
3. Or: the "Issues" tab → "New issue" → choose "賛同する / Endorse cherry".
   (Screenshot to be added later)
4. In "Name or handle", write the name you want in the list.
5. In "Link", paste your GitHub profile URL.
6. "One line" is optional.
7. Tick "I agree with the sentence in SIGNATORIES.md".
8. Click "Create" (or "Submit new issue") at the bottom.

## Door C: post on your own social account

1. Copy the sentence at the top of [SIGNATORIES.md](../SIGNATORIES.md).
2. Post it on your own account (X, Bluesky, Mastodon, note, a blog…).
3. Make the post public; a locked account can't be checked.
4. Copy the post's URL.
   (Screenshot to be added later)
5. Send the URL as a reply or DM to [@lock_sta](https://x.com/lock_sta) on X. If DMs are closed to you, reply instead.
6. Or leave it as a comment on [this note article](https://note.com/lock_sta/n/ne2540f427878).
7. If the name for the list differs from your display name, say so.

## What happens next

- Taiga checks it and updates the list, usually within a few days.
- Door A: your line appears when the Pull Request is merged.
- Doors B and C: Taiga adds the row for you.

## Please don't

- Don't change any line except your own.
- Don't post personal details beyond a handle (address, email, phone number and so on).
